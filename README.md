# The Last Pencil

A console-based game written in Python where a user plays against an automated mathematical bot. 

## Features
* Input validation (prevents text inputs, negative numbers, and out-of-bounds choices).
* Interactive turn-based loop.
* Unbeatable bot algorithm based on modulo operation (`% 4`) logic. 

## How to run
1. Ensure you have Python installed.
2. Run `main.py` in your terminal.
